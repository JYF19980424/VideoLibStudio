# VideoLibStudio 视频库管家

> 本地视频库管理工具，自动扫描、分类、整理你的视频文件。

## 这是什么

VideoLibStudio 是一款桌面端视频库管理软件，帮你把散落在电脑各个文件夹里的视频文件自动整理成一个带封面、带标签、可搜索的可视化图库。

**本仓库为开源基础版，包含核心本地功能。高级版包含更多联网和自动化功能，详见文末。**

---

## ✨ 功能特性

### 🆓 开源版已包含（完全免费）

- 📂 **本地视频扫描**：自动扫描指定文件夹，识别视频文件
- 🏷️ **自动番号识别**：从文件名中自动提取番号（如 ABC-123）
- 🖼️ **封面墙浏览**：缩略图模式浏览你的视频库
- 🔍 **多维度搜索**：按番号、标题、女优、标签筛选
- 🏷️ **标签管理**：自定义标签，批量分类
- 📊 **本地数据库**：所有数据存在本地 SQLite，不上传你的文件
- 📤 **导出功能**：导出 CSV、NFO 文件
- 🗂️ **文件整理**：按系列/女优自动分类复制/移动文件
- ⏱️ **播放时刻记录**：给视频打标记，记住看到哪了
- 🎬 **本地播放器调用**：一键打开默认播放器
- 🧠 **智能标签分析**：基于本地规则的自动分类

### 💎 高级版独有（付费）

- 🌐 **在线刮削**：自动从网络获取封面、演员、简介
- 📡 **新作监控**：订阅系列/女优，自动提醒新作更新
- ☁️ **云端数据库**：持续更新的番号元数据库（每日更新）
- 🔄 **自动更新**：软件一键升级到最新版
- 💾 **网盘接入**：115网盘 / 迅雷 / Alist / WebDAV / SMB 直接扫描
- 🤖 **AI 智能标签**：AI 自动分析视频内容打标签
- 🌐 **多语言翻译**：AI 自动翻译标题和简介
- 📺 **局域网共享**：手机/平板远程访问你的视频库
- 👤 **演员智能推荐**：基于观看历史的演员推荐算法

## 🚀 快速开始

### 从源码运行（开发者）

环境要求：
- Python 3.10+
- Windows 10/11

```bash
# 安装依赖
pip install pywebview flask opencv-python requests

# 运行
python app.py
```

### 直接使用（普通用户）

去 Release 页面下载 exe 安装包，双击即可运行，无需安装。

## 🛠️ 技术栈

- **后端**：Python + Flask
- **前端**：HTML / CSS / JavaScript（单页应用）
- **桌面窗口**：pywebview
- **数据库**：SQLite
- **打包**：PyInstaller

## 📁 项目结构

```
开源版/
├── app.py              # 主程序入口
├── core/
│   ├── api.py          # 后端 API（前端 JS 调用）
│   ├── database.py     # 数据库操作（SQLite）
│   ├── scanner.py      # 本地视频扫描引擎
│   ├── scraper.py      # 元数据刮削
│   ├── translator.py   # 翻译模块
│   ├── config.py       # 全局配置
│   ├── preview.py     # 视频预览/缩略图生成
│   └── exporter.py      # 导出功能（CSV/NFO）
├── ui/
│   ├── index.html      # 主页面
│   ├── app.js          # 前端逻辑
│   └── style.css       # 样式
└── README.md
```
